Как это выглядит

Теперь и на Android

Тот же неоновый дизайн, «Моя волна», чарт, поиск, тексты караоке, эквалайзер — и ИИ-диджей с той же нейросетью BeatNet: на Android она слышит биты так же, как на iPhone.

BeatNet — своя нейросеть

Чтобы сводить по битам, нужно точно знать, где они. Для этого в Yokayo своя маленькая нейросеть.

  1. Слышит ~12 секунд вокруг каждого момента: 8 расширяющихся свёрток, 31 тыс. параметров.
  2. Находит доли и сильные доли, из них — точный темп и сетку тактов.
  3. Честно говорит, когда не уверена — и тогда диджей не сводит по битам, а меняет трек через эхо.
  4. Работает на телефоне за полсекунды на трек, без интернета — на iPhone и на Android.

TransitionNet — нейросеть сама сводит

Вторая своя нейросеть. Она не выбирает переход из списка — она его рисует: на каждую долю решает, как двигать громкость, бас, середину, фильтры, эхо и реверб обеих дек.

  1. Слышит оба трека по долям: бас, середину и верх, темп, тональность, дроп.
  2. Получает «настроение» — случайный вектор, поэтому на одну пару каждый раз новый переход.
  3. Училась у диджеев и сама: сначала на шаблонах, потом по «судье» — басы не спорят, громкость ровная, смены на сильную долю.
  4. Видно, как она думает: в DJ-лаборатории светятся нейроны и бегут импульсы.

Открытый исходный код

Весь код приложения на GitHub под лицензией MIT. Никакой телеметрии и чужих серверов: приложение общается только с Яндекс Музыкой.

ios/ — приложение для iPhone на SwiftUI
android/ — приложение для Android на Kotlin и Jetpack Compose
docs/ — этот сайт

Yokayo Music — неофициальный клиент. Не связан с Яндексом и Apple. Музыка воспроизводится по вашей подписке.
