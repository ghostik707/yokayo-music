# Yokayo Music для Android

Yokayo для Android — тот же дизайн, что на iPhone: неоновый фон с частицами, анимированная «Моя волна», плавающая панель вкладок.

- главная: «Моя волна», «Собрано для вас», «Чарт», «Новые релизы»;
- «Обзор», «Медиатека», поиск с жанрами и историей, страницы плейлистов, альбомов и артистов;
- полноэкранный плеер с живым фоном из цветов обложки, текстами караоке и очередью;
- эквалайзер на 10 полос с пресетами, качество для Wi‑Fi и мобильной сети, статистика прослушивания;
- **ИИ-диджей**: своя нейросеть BeatNet, каждый переход сочиняется заново, DJ-лаборатория, умная очередь;
- фоновое воспроизведение, управление из шторки и с экрана блокировки.

Готовый APK — в [Releases](https://github.com/ghostik707/yokayo-music/releases/latest). Android 8+.

## Сборка

```bash
cd android
./gradlew assembleRelease
```

Нужны JDK 17 и Android SDK 35 (`sdk.dir` в `local.properties`).

## ИИ-диджей

`audio/` — свой звуковой движок (AudioTrack, две деки, бас/середина/срезы, эхо, реверб, подстройка темпа), нейросеть BeatNet с теми же весами, что на iPhone (`assets/BeatNet.bin`), анализ треков и ИИ-композитор переходов.
