# Yokayo Music

Открытый неофициальный клиент Яндекс Музыки в стиле Apple Music — с DJ-режимом, который сводит треки в непрерывный сет прямо на телефоне.

> Не связан с Яндексом и Apple. Музыка воспроизводится по вашей подписке Яндекс Плюс. Никаких взломов, обходов подписки и чужих треков в репозитории.

## Что умеет

- **Дизайн Apple Music**: тёмная тема с частицами, живые обложки, обложка на весь экран блокировки (iOS 26).
- **«Моя волна»** с новыми сессиями, анимированная карточка, которая пульсирует в такт треку.
- **DJ-режим с ИИ**: своя нейросеть BeatNet находит доли и сильные доли, планировщик кладёт интро нового трека на аутро старого, меняет басы на дропе, при несовместимом темпе уходит в эхо. DJ-лаборатория — переход между двумя любыми треками.
- **Умная очередь**: следующим ставится трек, который лучше сводится по темпу и тональности.
- **Синхронные тексты** в стиле караоке, карточки строк для сторис.
- **Эквалайзер** на 10 полос с пресетами и своим профилем, ровная громкость (−14 LUFS), кроссфейд.
- **Качество** отдельно для Wi‑Fi и мобильной сети.
- **Своя музыка** (MP3, FLAC, M4A, WAV), свои плейлисты, добавление в плейлисты Яндекса.
- **Виджеты**, Пункт управления, Siri и «Команды», таймер сна, Sped up / Slowed + reverb, статистика прослушивания.

## Структура

```
ios/        приложение для iPhone (SwiftUI, iOS 18+)
android/    приложение для Android
docs/       сайт проекта (GitHub Pages)
```

### BeatNet

`ios/YokayoMusic/Audio/BeatNet.swift` — маленькая свёрточная сеть (≈31 тыс. параметров, 8 расширяющихся свёрток, слышит ~12 секунд вокруг каждого кадра). Готовые веса — `ios/YokayoMusic/Audio/BeatNet.bin`. Сеть работает целиком на устройстве через Accelerate, анализ трека занимает около полсекунды.

## Сборка iOS

1. Xcode 26+, откройте `ios/YokayoMusic.xcodeproj`.
2. Зависимость [YM-API](https://github.com/p0rterB/YM-API) подтянется через Swift Package Manager.
3. Соберите схему `YokayoMusic`. Для установки без подписи — Release без подписи и ad-hoc `codesign`, как в релизах.

Готовые IPA — в разделе [Releases](../../releases).
